# hanzi_medians.json · 数据致谢 (Attribution)

本文件（`hanzi_medians.json`）是从 **[Make Me a Hanzi](https://github.com/skishore/makemeahanzi)** 的
`graphics.txt` 中提取的 `medians`（每字按正确笔顺的中心线折线，去掉 SVG 路径后约 6.5MB）。

**来源与许可：**
- 项目：Make Me a Hanzi，作者 Shaunak Kishore（`github.com/skishore/makemeahanzi`）。
- 字形数据 `graphics.txt` 派生自：
  - Arphic PL KaitiM GB — https://apps.ubuntu.com/cat/applications/precise/fonts-arphic-gkai00mp/
  - Arphic PL UKai — https://apps.ubuntu.com/cat/applications/fonts-arphic-ukai/
- 许可：**Arphic Public License**（Arphic Technology Co., Ltd.）。
  许可副本见 http://ftp.gnu.org/non-gnu/chinese-fonts-truetype/LICENSE

**使用注意：** 本库仅使用 `medians`（中心线）作为手写变形的输入，自行生成笔迹轮廓；
不随库分发 SVG `strokes`。若再分发本数据文件，请保留本致谢与 Arphic PL 许可。
